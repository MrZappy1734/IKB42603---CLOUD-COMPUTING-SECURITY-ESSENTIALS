# Quiz W2

## Cloud Computing Study Notes

1. **Question:** For easier permission management, policies should preferably be attached to?  
   **Answer:** IAM Groups

2. **Question:** Which tool creates a local Kubernetes cluster?  
   **Answer:** Docker Desktop

3. **Question:** Which service model provides virtual machines?  
   **Answer:** IaaS

4. **Question:** Which AWS identity has unlimited privileges?  
   **Answer:** Root User

5. **Question:** Which deployment model combines private and public cloud?  
   **Answer:** Hybrid Cloud

6. **Question:** A Kubernetes cluster consists of?  
   **Answer:** Multiple nodes

7. **Question:** Which endpoint is commonly used with LocalStack?  
   **Answer:** http://localhost:4566

8. **Question:** Which service model requires customers to manage the operating system?  
   **Answer:** IaaS

9. **Question:** In the ARN arn:aws:s3:::my-bucket, which component represents the AWS service?  
   **Answer:** aws

10. **Question:** Access keys are mainly used for?  
    **Answer:** Programmatic access

11. **Question:** The smallest deployable unit in Kubernetes is?  
    **Answer:** Node

12. **Question:** A collection of IAM users is called?  
    **Answer:** IAM Group

13. **Question:** Which IAM component contains permissions?  
    **Answer:** IAM Policy

14. **Question:** Which deployment model provides the MOST control?  
    **Answer:** Private Cloud

15. **Question:** Which is NOT an essential characteristic of cloud computing?  
    **Answer:** Measured Service

16. **Question:** Google Docs is an example of?  
    **Answer:** PaaS

17. **Question:** Cloud computing refers to?  
    **Answer:** Delivering computing resources over the Internet

18. **Question:** Which account should never have access keys created for routine use?  
    **Answer:** IAM User

19. **Question:** A node is?  
    **Answer:** A worker machine

20. **Question:** What does ARN stand for?  
    **Answer:** Amazon Resource Name

21. **Question:** Which characteristic allows cloud resources to automatically grow or shrink?  
    **Answer:** Rapid Elasticity

22. **Question:** Which AWS CLI command verifies the current identity?  
    **Answer:** aws iam whoami

23. **Question:** Which security principle gives users only the permissions required to perform their tasks?  
    **Answer:** Principle of Least Privilege

24. **Question:** Docker is mainly used to?  
    **Answer:** Run containers

25. **Question:** Which ARN component identifies the AWS account that owns the resource?  
    **Answer:** Account ID

26. **Question:** Which AWS-managed policy provides full administrative access?  
    **Answer:** RootPolicy

27. **Question:** If an access key is compromised, what should be done first?  
    **Answer:** Deactivate or rotate the key

28. **Question:** LocalStack is used because it?  
    **Answer:** Simulates AWS services locally

29. **Question:** Which IAM identity is normally used as a temporary identity?  
    **Answer:** IAM User

30. **Question:** Which command lists Kubernetes nodes?  
    **Answer:** docker ps
